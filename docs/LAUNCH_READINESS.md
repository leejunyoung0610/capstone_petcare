# 출시 준비 체크리스트 (PetCare / Ganadi)

데모 심사와 실제 배포 전에 **당장 코드로 반영한 항목**과 **운영·법무에서 따로 해야 할 항목**을 구분했습니다.

## 코드베이스에 반영된 항목 (예시)

- API 기본 보안 헤더 (`SecurityHeadersMiddleware`)
- `/health`에서 DB `SELECT 1`로 연결 여부 확인
- 선택적 빌드 라벨 `SERVICE_BUILD_LABEL` (`/`·`/health`에 `build` 필드)
- 진단 이미지 업로드: 크기 5MB 제한, JPEG/PNG MIME·시그니처 검증
- 프론트: 개인정보·이용약관 요약 페이지 및 푸터·로그인·회원가입 링크
- 회원가입 시 약관·개인정보 동의(필수)
- AI 스크리닝·결과 화면 면책 배너 강화

## 배포·운영에서 확인할 것

- **HTTPS**: 프로덕션 전 구간 TLS, HSTS는 리버스 프록시(Nginx 등)에서 검토
- **비밀값**: `SECRET_KEY`, DB 비밀번호, Kakao/S3/VAPID 등은 환경변수·시크릿 관리, 저장소에 커밋 금지
- **CORS**: `CORS_ORIGINS`를 실제 프론트 도메인만 허용하도록 최소화
- **로그·PII**: 접근 로그에 개인정보·토큰 노출 방지, 보관 기간 정책
- **백업·복구**: DB 스냅샷, 업로드 파일(S3 또는 디스크) 복구 시나리오
- **관측**: 헬스 프로브가 `/health`를 사용하는지, 장애 시 알림 연동

## 법무·준수 (정식 서비스 전 권장)

- 개인정보 처리방침·이용약관 **전문** 검토 및 동의 UX와 서버 정책 일치
- 수의사법·의료기기·동물보건 관련 표현·광고 규정 검토
- AI 고지 문구를 마케팅·앱스토어 정책에 맞게 정리

## 데모 시연 팁

- 시연 계정·시드 데이터·AI 서버 가용성을 미리 확인
- 네트워크 차단 시 오류 메시지가 사용자에게 적절히 보이는지 확인
