# 변경 이력 요약 (2026년 5월 세션)

데모·출시 준비 및 모바일 UX 중심 변경 사항입니다.

## 백엔드

- **진단 PDF**: `Authorization` 또는 쿼리 `token`으로 인증 가능. 응답 `Content-Disposition`을 `inline`으로 조정해 모바일 내장 PDF 뷰어와 호환.
- **진단 보고서(JSON)**: `DiagnosisResult.report_data` 컬럼으로 Claude 리포트 저장. `GET /diagnosis/{id}/report`로 조회·생성·캐시.
- **진단 삭제**: `DELETE /diagnosis/{id}` (소유자만).
- **결제·보안 등**: Toss 결제 라우터, 보안 헤더, 결제 주문 마이그레이션, 설정 예시 보강 등 (기존 작업 포함).

## 프론트엔드

- **질환 백과**: `frontend/src/data/diseases.ts` 중앙 데이터 (백과 목록·상세 공통 사용).
- **홈**: 하단 탭바·플로팅 AI 버튼 노치, 히어로 정리.
- **수의사 검색**: 가나디 인증만 모드 시 등록 병원 전체 로드, 카카오맵 길찾기 액션 시트.
- **진단 결과**: 인앱 보고서 보기, PDF는 blob 로딩 후 저장·공유(모바일 로딩 오버레이).
- **진단 이력**: 삭제·보고서 배지, 햄버거 외부 탭·경로 변경 시 메뉴 자동 닫힘.
- **마이페이지**: 설정을 탭으로 통합, 프로필 헤더 레이아웃 정리.
- **기타**: 법적 페이지·토스 결제 콜백 라우트, Vite 프록시 `127.0.0.1`, 진단 API·스토어 조정.

## 모델·기타

- **LFS**: `cat_best.pth` 포인터가 갱신된 경우 원격 저장소에 LFS 업로드가 필요할 수 있습니다.
- **평가 결과**: `models/classifier/eval_results/` 일부 파일 추가(선택 추적).
